# AgentDock Parity Notes

MaxTag should catch up to AgentDock on operational reliability while keeping a
different product shape: one workspace-level bot serving many projects across
many clients.

## Product Constraint

AgentDock is a local workbench. MaxTag is a shared collaboration bot. Parity
should be measured by operational capability, not by copying AgentDock's object
model directly.
